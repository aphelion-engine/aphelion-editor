Drop a ``.py`` plugin module in this folder. Each file is imported when
the editor boots. Plugins must import ``aphelion_sdk`` only.

User-writable copy: ``userdata/plugins/``

Guides: ``docs/plugins.md`` in this repo, and ``../aphelion-sdk/docs/authoring.md``.

Example: ``../aphelion-sdk/examples/grayscale_effect.py``
