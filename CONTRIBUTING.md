# Contributing to Aphelion Editor

Thank you for your interest in contributing to **Aphelion Editor**, the node‑based visual editor for the Aphelion Engine.  
This document explains how to set up the project, follow coding standards, submit changes, and participate in development.

---

## Ways to Contribute

- Fix bugs or improve stability  
- Add new nodes or enhance existing ones  
- Improve UI/UX in the editor  
- Optimize performance (graph layout, rendering, caching, etc.)  
- Improve documentation or examples  
- Add plugins using the plugin system  
- Report issues with clear reproduction steps  

Check the GitHub Issues page for items labeled **good first issue** or **help wanted**.

---

## Development Setup

### Requirements

- Python 3.11+
- PyQt6
- FFmpeg (for media nodes)
- Git
- A modern GPU (recommended)
